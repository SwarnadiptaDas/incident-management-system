1. The Vision

Sentinel-IMS is a distributed incident management system engineered for extreme reliability. It doesn't just store logs; it proactively manages the incident lifecycle using mission-critical architecture patterns.

🚀 High-Throughput Ingestion

Utilizes Redis-backed buffering and Async Backpressure Handling to sustain bursts of 10,000 signals/sec without API degradation.

🧩 Atomic Debouncing

Implements a Strict 10s Window to merge duplicate signals into single Work Items, preventing database storms and alert fatigue.

🏗️ Multi-Store Persistence

Hybrid storage architecture: PostgreSQL for transactional state, MongoDB for high-volume audit logs, and Redis for real-time aggregation.

🛡️ Pattern-Driven Logic

Full implementation of the State Pattern for lifecycle safety and the Strategy Pattern for severity-based alerting logic.

2. Advanced SRE Observability

Beyond basic logs, the system provides deep visibility into its internal health and data throughput.

  • Deep Health Metrics: Monitoring active connections for Postgres, Mongo, and Redis clusters.
  • Time-Series stats: Minutely signal aggregation per component for immediate capacity planning.
  • Structured Telemetry: Real-time logging of signals/sec and buffer depth in the worker engine.
